blockAccess

Geolocation & VPN Access Control for PHP

How It Works

IP Detection

The script identifies the client's IP address using $_SERVER['REMOTE_ADDR'], with a fallback to $_SERVER['HTTP_X_FORWARDED_FOR'] for proxy environments.

API Query

The detected IP is sent to the ip-api.com service to fetch comprehensive geolocation data, including country, country code, and VPN/proxy usage.

Access Logic

Based on rules defined in access.txt, the system determines whether to grant or deny access. Rules include allow, block, and only, with only overriding other restrictions.

Error Handling

In case of API call failures or errors, access is granted by default, ensuring a graceful fallback and preventing unintended blocks.

Features

  • Detects client's country based on IP address.
  • Identifies if the client is using a VPN or proxy.
  • Implements flexible access control logic using a simple configuration file (access.txt).
  • Provides user-friendly error messages and access decisions.

How to Set Up

  1. Download: Clone or download the blockAccess repository to your PHP server.
  2. Placement: Place the access_control.php file in your server's web directory.
  3. Configuration: Create an access.txt file in the same directory with your desired access rules.
  4. Integration: Include the script in any PHP file where you want to restrict access: 
    <?php include "access_control.php"; ?>
  5. Permissions: Ensure your server can make outbound HTTP requests to http://ip-api.com.

Example access.txt:

# This file contains access rules for the website:
# - 'allow' specifies countries that are explicitly allowed to access the site.
# - 'block' specifies countries that are explicitly denied access to the site.
# - 'only' specifies countries that are granted special access, overriding other restrictions.

allow_vpn:false   # You can set your own value to disable vpn detection
allow:USA         # Visitors from the USA are explicitly allowed.
allow:Canada      # Visitors from Canada are explicitly allowed.
block:India       # Visitors from India are explicitly blocked.
block:Israel      # Visitors from Israel are explicitly blocked.
only:Malaysia     # Visitors from Malaysia are treated as Main Users, granted access regardless of other rules.

Customization

Access Rules

Easily modify the access.txt file to add, remove, or update country-specific access rules. This file gives you granular control over who can access your content.

VPN Policy

Adjust the if ($isVpn) block within access_control.php to fine-tune behavior for VPN users. Decide whether to allow, block, or handle VPN connections differently.

Important Notes

  • Ensure compliance with privacy and legal regulations when implementing geolocation-based restrictions.
  • The script relies on the availability and responsiveness of the IP-API service. Consider implementing caching mechanisms to reduce API usage and improve performance.
